# Student Management System

A console-based Student Management System built using Java and Object-Oriented Programming (OOP).

## Features

- Add a new student
- View all students
- Search for a student by ID
- Update student information
- Delete a student
- Exit the application
- Prevent duplicate student IDs

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
